Cara Mengisi Form Monitoring

Panduan dari mulai membuka formulir, mengisi data, memeriksa, hingga mengirim format ke WhatsApp Admin.

PILIH SESUAI KEBUTUHAN

Panduan fitur

9 topik
✎Form MonitoringPengisian, koreksi, dan pengiriman data›

Langkah mengisi formulir

  1. Dari Beranda, tekan Isi Form Monitoring.
  2. Baca keterangan serta syarat dan ketentuan yang ditampilkan, lalu setujui untuk melanjutkan.
  3. Isi setiap kolom sesuai paket dan perangkat yang digunakan. Periksa email, profil, jenis akun, durasi, tanggal login, jam login, perangkat, dan nomor WhatsApp.
  4. Setelah masuk ke halaman pemeriksaan, baca ulang seluruh data. Pastikan tidak ada salah ketik.
  5. Jika ada kesalahan, tekan Ubah data untuk kembali ke formulir.
  6. Jika sudah benar, tekan Kirim ke WhatsApp Admin. WhatsApp akan terbuka dengan format yang sudah disiapkan; periksa pesannya lalu kirim.
Tips: Simpan format monitoring dan ID Order. Jangan mengirim kata sandi atau kode OTP Netflix.
▤Riwayat MonitoringMelihat, mencari, dan membuka pesanan›

Melihat riwayat

  1. Buka menu Monitoring di navigasi bawah.
  2. Gunakan kolom pencarian untuk mencari berdasarkan ID Order, email, nomor WhatsApp, profil, atau tanggal yang tersimpan.
  3. ID dapat dicari dengan awalan RZH- maupun angka ID tanpa awalan.
  4. Tekan kartu pesanan atau tombol detail untuk melihat rincian yang tersimpan.
Riwayat yang ditampilkan di bagian arsip lokal tersimpan pada browser/perangkat ini. Riwayat lokal tidak otomatis sama dengan konfirmasi admin atau data Firebase.
☷Filter dan PengurutanMenyaring dan mengurutkan daftar pesanan›

Menyaring pesanan

  1. Masuk ke menu Monitoring.
  2. Pilih status Semua, Masih Aktif, Segera Habis, atau Sudah Habis.
  3. Jika tersedia, pilih jenis akun Sharing atau Semi Private.
  4. Gunakan pilihan Urutkan untuk memilih terbaru, terlama, tanggal habis terdekat/terjauh, atau email A–Z.
Filter dan pengurutan hanya mengubah tampilan daftar; tidak mengubah data pesanan.
#ID OrderMengenali, mencari, dan menyalin ID›

Menggunakan ID Order

  1. Temukan ID Order pada kartu atau detail pesanan.
  2. Tekan Salin ID untuk menyalin nomor saja.
  3. Untuk mencari pesanan, tempelkan ID lengkap (contoh RZH-202611145774) atau angka ID tanpa awalan.
ID Order membantu membedakan pesanan saat berkomunikasi dengan Admin. Simpan ID bersama format monitoring.
▣Salin Format MonitoringMenyalin dan menyimpan rincian pesanan›

Menyalin format

  1. Buka menu Monitoring dan temukan pesanan yang dimaksud.
  2. Tekan Salin Format pada kartu pesanan.
  3. Tempelkan hasil salinan ke catatan pribadi atau tempat aman yang mudah ditemukan kembali.
  4. Pastikan ID Order ikut tersimpan agar format mudah dicocokkan dengan pesanan.
Simpan format untuk keperluan pengecekan atau klaim sesuai ketentuan layanan.
◷Masa Aktif dan PengingatMemahami status serta tanggal habis paket›

Memahami status paket

  • Masih Aktif: tanggal habis masih di luar periode peringatan paket.
  • Segera Habis: paket sudah masuk periode peringatan berdasarkan durasinya.
  • Berakhir hari ini: tanggal habis jatuh pada hari ini.
  • Sudah Habis: tanggal habis sudah terlewati.

Melihat pengingat

  1. Buka menu Masa Aktif.
  2. Lihat status dan tanggal habis pada kartu paket.
  3. Tekan detail pesanan untuk melihat informasi lebih lanjut.
  4. Gunakan tombol pengajuan perpanjangan jika ingin menghubungi admin mengenai perpanjangan.
Status dihitung dari tanggal pada catatan monitoring perangkat, bukan pemeriksaan langsung ke akun Netflix. Pengingat website tampil saat website dibuka.
↻Ajukan PerpanjanganMeminta bantuan untuk memperpanjang paket›

Cara mengajukan

  1. Buka menu Masa Aktif atau detail pesanan.
  2. Pilih pesanan yang ingin diperpanjang.
  3. Tekan Ajukan Perpanjangan.
  4. Ikuti arahan WhatsApp atau instruksi yang ditampilkan dan tunggu konfirmasi admin.
Pengajuan bukan berarti perpanjangan sudah berhasil. Pastikan mendapat konfirmasi dari Admin.
▧Pembayaran dan KonfirmasiQRIS serta konfirmasi kepada admin›

Setelah melakukan pembayaran

  1. Ikuti instruksi pembayaran yang diberikan pada alur pemesanan.
  2. Periksa kembali nominal dan tujuan pembayaran sebelum menyelesaikan transaksi.
  3. Kirim bukti pembayaran kepada Admin sesuai instruksi.
  4. Tunggu pemeriksaan dan konfirmasi Admin.
Website tidak memverifikasi pembayaran QRIS secara otomatis. Status pembayaran tetap perlu dikonfirmasi oleh Admin.
!Kendala Umum dan KeamananSolusi awal dan menjaga data pesanan›

Jika mengalami kendala

  • Gagal menyalin: coba tekan kembali. Jika browser tidak mendukung, pilih teks lalu salin secara manual.
  • Riwayat tidak ditemukan: periksa ejaan email/ID dan pastikan menggunakan browser serta perangkat tempat riwayat lokal disimpan.
  • WhatsApp tidak terbuka: pastikan aplikasi atau browser dapat membuka tautan WhatsApp, lalu coba lagi.
  • Data pesanan berbeda: hubungi Admin dan sertakan ID Order serta format monitoring.

Keamanan data

  • Jangan membagikan kata sandi atau kode OTP.
  • Simpan ID Order dan format monitoring secara pribadi.
  • Periksa kembali nomor tujuan dan rincian sebelum mengirim pesan.
Tidak ada panduan yang cocok. Coba kata kunci lain.

Keterangan & penting!

Ikuti langkah berikutBaca keterangan, gulir sampai paling bawah, centang persetujuan, lalu tekan “Saya Mengerti, Mulai Isi Form”.
📌 Tujuan penggunaan data
Data yang kamu isi digunakan oleh seller untuk mencatat pesanan, mencocokkan perangkat, dan membantu memantau masa aktif paket. Website ini bukan layanan resmi Netflix dan tidak berafiliasi dengan Netflix.
🔒 Privasi data
Data yang dikirim akan diterima oleh admin dan digunakan sesuai keperluan monitoring serta pelayanan akun. Jangan mengirimkan informasi sensitif seperti password atau kode OTP.
⚠️ Perhatian
Isi seluruh data dengan benar, lengkap, dan sesuai perangkat yang digunakan. Kesalahan pengisian, data tidak lengkap, atau informasi yang tidak sesuai dapat menyulitkan proses validasi dan klaim garansi. Jika format tidak diisi atau data tidak sesuai ketentuan, akun dapat dianggap tidak bergaransi sesuai kebijakan seller.

📌 Selanjutnya harus tekan apa?
↓ Jika data sudah benar, lanjutkan ke tombol biru “Kirim ke WhatsApp Admin”.

Salin format adalah pilihan cadangan jika WhatsApp tidak terbuka atau kamu ingin mengirimnya secara manual.
